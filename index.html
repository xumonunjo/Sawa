Guide rapide de SÂAWAH

Pour d’autres langues, utilise la traduction de page si ton navigateur la propose.

Tambour
  • Touche Activer le son, puis frappe le centre pour le grave, les anneaux pour les sons plus secs et le bord pour les graines.
  • Balaye le bord pour faire sonner les perles. Glisse le long de l’axe vertical pour faire monter ou descendre la hauteur du son. La cloche et le fil du nom se jouent aussi.
  • La pression fait varier le volume de la frappe. Si l’écran fournit seulement la taille du contact, joue avec le bout du doigt pour un son plus doux et avec la pulpe pour un son plus fort. Certains appareils donnent un volume fixe.
  • Touche une zone pour la sélectionner dans le séquenceur et le sampler. Active Repères pour afficher les réglages du pad.
  • Volume de chaque pad. Pose le doigt sur l’arc choisi et maintiens-le un court instant. Sans lever le doigt, suis l’arc dans le sens des aiguilles d’une montre ↻ pour monter le volume, ou dans le sens inverse ↺ pour le baisser. Relâche le doigt pour garder ce réglage.
Séquenceur
  • Choisis le tempo, la mesure et le nombre de pas, puis touche une case pour placer une frappe. Glisse verticalement sur une case pour régler son volume.
  • Touche Lire pour écouter la boucle ou Enregistrer pour y ajouter ce que tu joues sur le tambour. Touche Terminer la prise quand tu as fini.
  • Mixage affiche les réglages des pistes. Le point coupe la piste. D dose le delay, R la réverbération et P règle la hauteur. Exporter prépare un WAV stéréo ou un fichier MIDI avec le nombre de boucles choisi.
Sampler
  • Touche un pad ou choisis-le dans Portion. Importe un fichier audio ou utilise Enregistrer au micro.
  • Déplace Début et Fin pour isoler un son. Compare Écouter tout et Écouter la coupe avant de jouer le pad.
  • Pour réutiliser un son sur un autre pad, choisis la nouvelle portion, sélectionne le son dans la Bibliothèque puis touche Utiliser sur cette portion.
